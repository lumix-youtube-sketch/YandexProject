# Livi

Веб-приложение для отслеживания привычек, задач и заметок. Помогает вырабатывать дисциплину: отмечай выполнение привычек по дням, веди список дел с приоритетами и дедлайнами, сохраняй заметки — всё в одном месте под своим аккаунтом.

**Автор:** Мешков Матвей

## Технологии

- Python 3 / Flask
- Flask-SQLAlchemy + SQLite
- Внешний API цитат

## Запуск

```bash
pip install flask flask-sqlalchemy requests
python app.py
```

Открыть в браузере: http://127.0.0.1:5000
